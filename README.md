# DFT-doping-interface
This repository contains VASP input files and post-processing scripts for the manuscript.

## Contents
- bulk: VASP input files and CONTCAR files for the pure CuZr-B19’ bulk structure and bulk-doped models with various elements
- Surface: VASP input files and CONTCAR files for the pure CuZr-B19’ (100) surface and its doped models with various elements
- GB: VASP input files and CONTCAR files for the pure CuZr-B19’ grain boundary structure and grain-boundary-doped models with various elements
- Silp: VASP input files, CONTCAR files, energy calculation scripts and corresponding results for slip calculations of grain boundaries doped with representative elements (O, Si)
- bader: scripts for Bader charge analysis
